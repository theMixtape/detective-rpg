# 🔍 London: Таємниця детектива (London: The Detective's Secret)

> **Консольна текстова детективна RPG на JavaScript**

Лондон, 1984 рік. Вулиці, оповиті густим туманом та проливним дощем, приховують темні таємниці. Ви — детектив Віктор. Ваше завдання — розслідувати загадкову та насильницьку смерть майстра-годинникаря Генріха. Збирайте докази, балансуйте між ресурсами та ризиком, уникайте патрулів Скотленд-Ярду й викрийте змову на найвищому рівні.

---

## 🎯 Особливості гри (Features)

* **🎭 Нелінійне розслідування:** Досліджуйте ключові локації міста: майстерню годинникаря, підпільний паб, міський морг та архів ратуші.
* **🔍 Інтелектуальна система зачіпок:** Використання перевірки `.some()` гарантує унікальність доказів і запобігає їх дублюванню.
* **🚨 Динамічний рівень підозри (`playerSuspicion`):** Кожне ваше рішення (особливо силові методи чи ризиковані допити) збільшує або зменшує увагу поліції.
* **💰 Баланс ресурсів та вибору:** Обирайте між мирними підкупами за кредити, ризикованими допитами з примусом та хитрістю.
* **🌧️ Погода як перешкода (`loseClue`):** Атмосферна випадкова подія через лондонську негоду, яка з певним шансом може коштувати вам втрати важливої зачіпки по дорозі.
* **🏛️ Фінал у Годинниковій вежі:** Кульмінаційна розв'язка з кількома варіантами розвитку подій (правосуддя, шантаж або силовий штурм), результат якої залежить від зібраних доказів та рівня підозри.

---

## 🛠️ Технологічний стек (Tech Stack)

* **Мова:** JavaScript
* **Інтерфейс:** Console / Dialog-based (`prompt`, `alert`, `console.log`)
* **Архітектура:** Модульні функції локацій, глобальний менеджмент стану гравця (Global State Management).
